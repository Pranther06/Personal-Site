# assets/

Put your images here (hero photo, gallery photos, etc.).

Then reference them from the content files, for example:
- Hero photo in `content/profile.js`: `photo: "./assets/me.jpg"`
- Gallery photos in `content/photos.js`: `{ src: "./assets/trip.jpg", ... }`

Tip: keep images reasonably sized (e.g. ≤ 1600px wide, compressed) so the site
loads fast — especially on GitHub Pages.
